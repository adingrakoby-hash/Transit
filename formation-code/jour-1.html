Contenu

Les trois modules du jour.

Module 1 · Comment fonctionne le web

  • Le navigateur (Chrome, Safari) lit des fichiers et les affiche à l'écran.
  • Le serveur est un ordinateur allumé en permanence qui stocke ces fichiers.
  • Le nom de domaine (novakgroupe.com) est l'adresse lisible qui pointe vers ce serveur.
  • Une page web repose sur trois langages : HTML pour le contenu, CSS pour l'apparence, JavaScript pour l'interaction.

L'image à retenir : HTML est la structure de la maison, CSS la peinture et la décoration, JavaScript l'électricité.

Exercice d'observation · 10 min

Ouvrez le site de votre choix dans Chrome, faites un clic droit puis « Inspecter ». Repérez un titre, un paragraphe et une image dans le code. Modifiez un texte en direct : il ne change que sur votre écran. Vous venez de voir le HTML d'un vrai site.

Module 2 · HTML, le squelette

  • Une balise s'ouvre et se ferme : <p>…</p>.
  • Les balises essentielles : h1 à h3, p, a, img, ul et li, section.
  • Un attribut précise une balise : href pour un lien, src et alt pour une image.
  • Une seule balise h1 par page : c'est le titre principal, important pour Google.

Astuce VS Code : tapez ! puis Entrée dans un fichier .html vide pour générer la structure de base.

<!-- index.html -->
<!doctype html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Mon activité</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <section class="carte">
      <h1>Awa Traoré</h1>
      <p>Pâtisserie artisanale à Cocody</p>
      <ul>
        <li>Gâteaux d'anniversaire</li>
        <li>Commandes d'entreprise</li>
      </ul>
      <a href="https://wa.me/225XXXXXXXXXX">Commander sur WhatsApp</a>
    </section>
  </body>
</html>

Module 3 · CSS, l'habillage

  • Une règle CSS = un sélecteur + des propriétés : h1 { color: navy; }.
  • On cible une classe avec un point : .carte.
  • Le modèle de boîte : contenu, padding (intérieur), border, margin (extérieur).
  • Flexbox aligne les éléments en ligne ou en colonne : display: flex.
  • Pensez téléphone d'abord : la majorité de vos clients vous verront sur mobile.
/* style.css */
body {
  margin: 0;
  min-height: 100vh;
  display: flex;
  align-items: center;
  justify-content: center;
  background: #14285A;
  font-family: system-ui, sans-serif;
}
.carte {
  width: min(420px, 90%);
  padding: 32px;
  background: #fff;
  border-radius: 20px;
  border-top: 6px solid #C9A227;
}
.carte a {
  display: inline-block;
  padding: 12px 20px;
  background: #C9A227;
  color: #14285A;
  border-radius: 99px;
  text-decoration: none;
  font-weight: 700;
}

Mémo

Le glossaire du Jour 1.

Balise
Élément HTML entre chevrons, qui s'ouvre et se ferme.
Attribut
Information ajoutée à une balise, comme href ou alt.
Sélecteur
Partie d'une règle CSS qui désigne les éléments à styliser.
Classe
Nom réutilisable donné à des éléments pour les styliser ensemble.
Responsive
Page qui s'adapte à toutes les tailles d'écran.
Flexbox
Système CSS pour aligner et répartir des éléments.
Nom de domaine
Adresse lisible d'un site, par exemple novakgroupe.com.
Hébergement
Serveur qui stocke les fichiers du site et les rend accessibles.
